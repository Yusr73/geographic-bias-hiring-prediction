# Logistic Regression Implementation from Scratch

## Project Overview

Implementation of logistic regression using **gradient descent** and **Newton's method** to analyze the effect of geographic distance on hiring decisions.

## Key Features

* Implementation of **two optimization algorithms** from scratch
* **Mathematical derivation** included with LaTeX formulas
* **Comparison with scikit-learn** for validation
* Application to hiring data analysis

## Results

The analysis shows a **negative but weak relationship** between distance and hiring probability (β₁ = -0.011), indicating minimal geographic bias in the synthetic dataset.

## Technologies

Python, NumPy, scikit-learn (for validation), Jupyter Notebook
